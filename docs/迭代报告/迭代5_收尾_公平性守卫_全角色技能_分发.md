## 一、公平性守卫(L1 CommandExecutor)

| 动作 | 修复前 | 修复后 |
|---|---|---|
| 击杀 | 硬编码 4.5u 上限(超游戏最长档) | 按房间 KillDistance 档位(1/1.8/2.5)+0.6 余量,`AllowedKillDistance()` |
| 钻管 | 无职业守卫(船员也能钻) | `me.RoleCanUseVents()`(与 mod Vent.CanUse 同判据)→ `not_allowed:no_vent_role` |
| 修灯/修通讯 | 全图任意位置远程修 | 必须站在 Electrical/Comms 对应台 3u 内(`RequireNearConsole`) |
| 紧急会议 | `debug_call_meeting` 任何房主可用 | 仅 LocalGame(自托管 bot 局);在线真人局拒绝——紧急会议只能真人合法触发 |
| 补 bot | `spawn_bots` 任何房主可用 | 仅 LocalGame(dummy 不网络同步,online 房无意义) |
| 会议技能 | `use_ability` 仅 PLAYING | 放开 MEETING(HasButton/CouldUse/冷却仍全按 mod 判定,等价真人点击) |

配套:state.me 新增 `kill_distance`(允许击杀距离)与 `can_vent`,L3 据此决策。

**报尸/报警审计结论**(无需改动):report 已有 5.5u+视线遮挡双守卫;紧急会议走
`CmdReportDeadBody(null)`,游戏自身校验紧急冷却/破坏状态;做任务特权本就要求
人在台前+面板开 10 秒(TaskPrivilege)。

## 二、隐藏 bug 修复

1. **`use_sabotage`/`repair` 子参数字段名 `type` 与顶层指令路由 `type` 冲突**:
   `{"type":"repair"}` 时 `GetStr(d,"type")` 读到指令名本身,两条指令从未能正确指定
   破坏/修复类型。改为 `kind` 字段(兼容 `sab_type` 别名)。
2. **meeting.py `_append_out` 越权改输入偏移**:写输出文件后把 `self._offset`(输入
   chat_file 读取偏移)拉到文件末尾,真人对局中会吞掉写入期间其他玩家的新聊天行。已删。
3. **behavior.py 任务 watchdog 死代码**:`active_id` 非空的提前 `return` 使 150s 看门狗
   永不触发,卡死任务会永久占用任务槽。已挪到判定前。

## 三、全角色技能适配

感知/行动层本就全职业覆盖(StateCollector 枚举全部 CustomButton,`use_ability`
反查按钮点击,等价真人按热键)。本次补齐决策层:

- **行为引擎自动驾驶**(`behavior.py::_ability_tick`):13 个高置信白名单技能
  ready 即用(工程师修理/医生盾/老兵警戒/幸存者背心/追踪×2/保镖/看魂/拆弹/
  关灯/纵火狂浇油/狼人狂暴/幽灵工程师),8 秒节流,`auto_abilities` 开关
  (config.ini [behavior] / 面板 / POST /api/behavior 均可切)。
  击杀类职业刀(IsKillButton)统一走 kill 通道(含职业冷却);开会、开地图/摄像头
  面板、传送类技能**绝不自动用**(防自锁面板/打断节奏)。
- **面板**:技能卡片每项加「用」按钮(会议中也可点,会议技能通道);行为引擎卡片
  加「自动技能」开关与使用计数;快捷指令区新增 进/出管道、破坏(带类型下拉)、修灯。

**已知边界**:猜人链/末日预言等"会议内弹窗选目标"的多步技能,点击后弹出的选人
UI 不经 CustomButton,目前仅支持面板人工触发第一阶段(use_ability),选人交互的
自动化留待需要时再做。

## 四、分发整理(结论)

**mod 联机校验实证**:`GameStartManagerPatch` 对每个客户端比对 `Main.version` +
`ManifestModule.ModuleVersionId`(MVID,每次编译随机)。因此**所有参与者必须替换为
同一个我们构建的 `TheOtherUs.dll`**(官方 1.2.9.8 原版也不行,MVID 不同会禁用开局按钮)。

- 朋友已装 TheOtherUs 1.2.9.8 环境:只换 `BepInEx\plugins\TheOtherUs.dll` 一个文件。
- 朋友什么都没装:整目录拷 `aubody`(剔除 backup/皮肤解锁器等),Steam 启动。
- `ai.amongus.bridge.cfg` 无需分发(自动生成,默认即用);`agent\` 仅 AI 玩家机器需要。
- 交付物:`dist/TheOtherUs.dll` + `dist/分发说明.md`。
