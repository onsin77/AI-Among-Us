### 面板总控(新增,已实测)

- 左列「脚本总控」:开始接管(选 auto/crew/impostor,可勾选自动开新局)、停止接管、关闭脚本。
- HTTP:`/api/control`(GET 状态 / POST start|stop|shutdown)。
- 实测:①autostart 接管 → 自动开局并开始做任务;②停止 → 任务流 `walk_cmd_stop` 中止、行为回 monitor、角色停住、此后无新指令;③关闭 → agent 端口关闭、进程退出;④重启后可再次 start。
- 接管语义:start 只控制 agent 行为与会议,不负责启动游戏进程;shutdown 只退 agent,不退出游戏。

## 四、已知限制

1. **练习模式会议无法真实模拟**:假人不聊天/投票;聊天靠文件/面板喂入,投票靠 `debug_meeting_ff` 收尾。真人对局时 `state.chat` 已能读到游戏聊天。
2. `debug_set_role` 中途换角色可能让先前被击杀的假人复活(实测),人/鬼规则联调建议分两局。
3. 会议 AI 每次响应间隔 ≥6s;同一批发言不重复回应;模型档位默认 fast。
4. 行为引擎是规则版(巡逻/击杀/任务/报尸),不含策略推理;策略层留给迭代 4(fast AI 决策)。
5. 面板地图默认 8s 刷新一次;路径叠加需手动“规划路径”。
