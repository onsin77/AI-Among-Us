## 一、改动清单

### L1(`TheOtherUs-5093a00/TheOtherRoles/AIAmongUs/`)

#### Navigator.cs(重写核心)
- **栅格 0.25 格距**(原 0.5):0.5 格距会漏窄门/梯口,实测把东西两半图断开(65→99% 可达的关键之一)。
- **可站判定用玩家真实半径**:`PlayerRadius()` 读本地玩家 `CircleCollider2D.radius × 0.75`(钳 0.15~0.3)。曾用拍脑袋的 0.25,把能走人的窄门封死(Engine 东出口)。
- **胶囊边验证**:相邻可走格之间用 `Physics2D.CircleCastAll(半径=玩家半径)` 判通行,补 `Linecast` 测不出的"1 格宽伪通道"(格心各离墙 ≥ 半径、0.4 宽的胶囊却过不去)。
- **门盘强制**:门位置=真实通道,门周 0.5u 圆盘内格子强制可走(否则窄门洞被误封,整片区域变孤岛)。
- **锚点连通分量剪枝**:锚=任务台/管道/门/出生中心/全体玩家;无锚分量(坑洞内部/装饰密室)封死。
- **离墙距离场 + A\* 代价惩罚**:贴墙格 ×1.5~3.0,让路径走走廊中间,减少凹角卡死。
- **软避让**:卡死格周围 ±4 格在本次移动内代价 ×50(不硬封,唯一通路仍可用——硬封曾把窄出口堵死连坐 no_route)。
- **卡死判定改为"净进展"**:0.6s 内既无位移也没有向目标推进 0.25u 才算卡;贴墙滑行不再误判(此前误判导致正常行程 3 次 reroute 后 MOVE_FAILED)。
- **转向避障**:直行被 `CircleCast` 挡住时尝试 ±25°/±50°/±75°/±100°;探测层含 `LivingPlayersOnlyMask`(玩家间有物理碰撞),并**排除本地玩家自身 collider**(CircleCast 从自身发出必命中自己,曾导致转向永远触发、乱走)。
- **特殊边统一**:梯子 + 飞艇 GapRoom 移动平台。平台:轨道中段封虚拟墙(缺口无实体墙,栅格误判可走),两端注册特殊边;跟路到登乘点自动 `RpcUsePlatform()`,轮询到位(>3s 重发,18s 超时),乘坐期间游戏 `moveable=false`,导航不抢速度。
- **梯子**:到端点 1.6u 内自动 `RpcClimbLadder`,乘坐后 `_pathIdx` 正确推进(修:原实现乘完梯会走回头路)。
- **RoomGoal**:`move_to {room}` 目标由 `roomArea.bounds.center`(实测 Kitchen/Brig 中心在墙外)改为"房间 bounds 内 ∧ OverlapPoint ∧ 可走 ∧ 可达域 中距中心欧氏最近格"。
- **ConsoleApproach**:console 接近点 = 可达 ∧ 距 console ≤ Use 半径 的最近格;console 自身 collider 加入忽略表(否则台周全判阻挡,人永远站不进 usableDistance)。
- **诊断指令**:`nav_path`(规划不执行,返回 wp/goal/crossings)、`nav_dump`(栅格位图 + 可达域 + links + 原始梯子表)、`nav_probe`(LOS + collider 名)、`nav_info`(运行态)。
- **周期重建**:地图变化或空闲满 25s 重建(捕捉开关门/玩家位置变化)。

#### CommandExecutor.cs
- `move_to {room}` 改走 `Navigator.RoomGoal`。
- 新增 `nav_path`、`debug_players`(全员真实坐标,freeplay 调试用)、`debug_meeting_ff`(等价投票计时器到点的 `ForceSkipAll`)。

#### TaskPrivilege.cs
- **直接实例化迷你游戏并绑定自己的任务**:`Console.Use()` 走 `FindTask`(该台第一项未完成任务),任务台共用时会开出"别人的面板"(实测 `panel_did_not_open`);改为复刻 `Console.Use` 的实例化流程 + `mg.Begin(_task)`。
- 接近半径对齐游戏判据 `UsableDistance`(不再 ×0.85,避免把可行站位排除);到达后超距先做 1~2 次精确修正走位。
- `open_task` 前预检本图有无该任务台(无台立即 `task_no_console`,如 Airship 的 SubmitScan)。
- 面板被中途关闭 → `TASK_ABORT` + 回 task 台重开(拟真)。
- Abort/结束时清理遗留面板,防后续任务 `move_panel_open`。

## 四、已知限制(带入迭代 3)

1. **可达率 65%**:部分"可走格"落在真实孤岛(坑洞/装饰区),goal 选择只在可达域内,安全;但个别任务台可能因此不可达(如 `EnterIdCode` 台在会议桌心,最近可站格 5.3u → 诚实报 `too_far`/跳过)。后续可用平台/门特殊边重连或手工锚点解决。
2. **平台特殊边已实现但验收未真正用到**:GapRoom 东侧有门可达,路径不经过平台;需专项用例(把玩家放到无门路线)验证 `RpcUsePlatform` 乘坐链。
3. **关门破坏未处理**:栅格忽略全部门 collider(pod 开局门开着);若破坏关门,路径仍视为可走 → 卡住后 reroute 会绕行,但不会主动开门。
4. **假人会走动**:转向层动态规避,但仍可能短暂被挡;击杀流程已用实时坐标重试。
5. **freeplay 专属逻辑**:会议自动 Proceed、debug_* 指令仅 freeplay;真实联机需改走真人 host 的投票/Proceed。
