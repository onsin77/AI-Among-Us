## 二、修复清单

### P0(崩溃/功能静默失效/安全)

1. **凭据泄露**:`agent/config.ini`(DeepSeek+讯飞真实密钥)与 `tests/test_xfyun_auth.py`
   (硬编码同一套讯飞密钥)已提交并推到 GitHub。处置:双双出库(git rm --cached,文件留本机)、
   新增 `agent/config.example.ini` 模板、测试改从 config.ini/环境变量读、
   .gitignore 补规则。⚠️ **密钥仍在 git 历史与远端,必须去控制台作废重建**(见"遗留")。
2. **L1 MiniJson 深嵌套栈溢出**:TCP 口无鉴权,一行万级嵌套 `[[[…` 会让递归下降解析器
   StackOverflow(不可 catch,直接杀游戏进程)。加 `MaxDepth=64` 深度上限→`bad_json`。游戏内实测通过。
3. **L3 会议 AI"失聪"**:meeting.py `_responded_upto` 用列表绝对下标,而 `_statements`
   截断到 14 条后长度封顶,`14>14` 恒假→开过一次会(>14 条发言)后 AI 永不再回应聊天。
   改单调计数 `_total_statements`。
4. **L3 桥任务可被杀死**:bridge.run() 只捕网络异常,`world.apply` 抛其它异常(脏数据)
   会冲出任务→面板永久 disconnected 只能重启。改捕 Exception 自愈重连。
5. **git 卫生**:.gitignore 原有一行 `agent/` 会忽略 agent 下所有**新增**文件(未来迭代代码
   静默进不了库);115 个运行时产物出库(`__pycache__/*.pyc`、agent.log、logs.json、s.json、
   state_dbg.json、data/*.jsonl 运行输出、tmp_cua/ 83 个调试日志、TheOtherUs-5093a00/dist/
   过时 dll 副本);.gitignore 重写(LF,精确条目)。

### P1(特定条件触发错误)

6. **L1 可靠队列零客户端丢消息**:FlushLoop 先出队再判客户端数,agent 断线重连窗口内的
   event/ack 全部丢弃(必达契约破坏)。改为有客户端才出队。
7. **L3 会议 `_vote_requested` 永不复位**:喂过一次 vote 行后每轮都被迫投票且陈旧目标
   跨会议生效。消费后复位。
8. **L3 session freeplay 永不计局**:`games_started` 只在 LOBBY→PLAYING 递增,freeplay
   直开 MENU→PLAYING 不算,max_games 永不生效;顺带 `_playing_since/_end_sent` 等
   计时也不重置(bot 补位窗口失真)。改 `prev in ("LOBBY","MENU")`。
9. **L3 session PLAYING→LOBBY 不清重试计数**:对局中途回大厅(掉线/被踢)后
   `_start_tries>=6` 永久卡大厅。改为任何非 LOBBY→LOBBY 都复位。
10. **L3 session 开局参数发送失败不重发**:桥瞬断时 `_options_sent` 照样置真,可能
    0 内鬼直接判负。改按发送结果置位。
11. **L3 model 非 JSON 响应体崩出**:HTTP 200 但网关页时 `json.load` 抛 JSONDecodeError
    不在 ModelError 体系内→会议批次被静默消费丢弃。转 ModelError;meeting 侧配套:
    推理失败/无 key/非 JSON 输出都**不推进水位**,批次保留按 min_interval 重试。
12. **语音 setup/teardown 竞态**:相位抖动时两个 ensure_future 互踩,teardown 会把
    setup 刚建的 asr 置 None→整场会议无 ASR 且不自愈。加 `asyncio.Lock` 串行化。
13. **语音 `_my_speak` 后半段无兜底**:TTS/播放异常会让 `my_state` 卡 speaking→整场轮麦
    死锁;且我方轮次完全豁免超时。加 try/finally 强制收敛 + 超时兜底可达。
14. **语音 ws 死链永不检测**:`ping_interval=None` 关了保活,静默断链时 connected 恒真。
    开 ping_interval=15/ping_timeout=10(YY 实战时留意讯飞端 pong 行为)。
15. **讯飞签名时区写死 +0800**:非东八区机器必鉴权失败。改 `%z` 真实偏移(本机行为不变)。
16. **`import websockets` 未装时击穿**:语音 setup 任务静默死。改 ImportError 捕获降级。
17. **L1 AIHub.Tick 子步骤无隔离**:任何一步持续异常(如建图段)会让后续 DrainInbound
   永不执行=整桥瘫痪且只报一次日志。按步 SafeStep(bodies/collect/nav/task),每局重置计数。
18. **L1 byte 截断回绕**:target_id=256 经 `(byte)` 变 0 命中错误玩家(kill/vote/report 三处)。
    加 0-255 显式范围校验。
19. **L1 CmdInteract 违反共用台约束**:直接 `Console.Use()` 会开错面板(实测约束#11)。
    改为:该台挂着自己未完成任务时走 TaskPrivilege 同款 Instantiate+Begin 绑定;其余台仍 Use()。
