# 语音会议使用说明(迭代 4)

> 目标:AI 在会议里像真人一样用**语音**参与:听 YY 里大家的发言(实时转写+区分音色),
> 轮到自己立刻开口(TTS 经虚拟麦克风送回 YY),会后投票、定目标、复盘记经验。
> 面板地址不变:http://127.0.0.1:8765 (网页版即可承载,无需桌面版)。

## 一、一次性环境准备

### 1. YY 语音设置(关键)

| YY 设置项 | 应选设备 | 说明 |
|---|---|---|
| 播放设备(扬声器) | **CABLE Input** | 大家的声音进虚拟线,AI 才能听到 |
| 录音设备(麦克风) | **CABLE Output** | AI 的 TTS 从虚拟线进 YY |
| 发言方式 | 自由发言(不需要按键) | AI 靠软件控制何时说话 |

- 想让自己(人耳)也能听到大家:控制面板 → 声音 → 录制 → `CABLE Output` → 属性 → 侦听 →
  侦听此设备(输出到你的耳机)。不设也不影响 AI 工作。
- **YY 的回声消除保持开启**(默认开):否则大家会从虚拟线里听到自己的回声。
- 游戏内音量与 YY 无关;Among Us 本体的声音走默认设备即可。

### 2. VB-CABLE 参数(本机已就绪)

- 内部采样率 48000 Hz;`CABLE Input`/`CABLE Output` 高级属性建议锁 48k。
- 允许独占模式**不要**勾选(两个端点都是)。
- 程序自动按名字找设备(WASAPI 优先,自动回退 DirectSound/MME),可用
  `GET /api/voice/devices` 查看枚举结果。

### 3. 服务依赖

- **XTTS 语音合成**(本地):双击 `D:\ai\xtts\service\start.bat`(健康检查
  `http://127.0.0.1:17895/health`)。声音默认 `xiaoyan`,可换 `xiaofeng`。
- **讯飞 RTASR-LLM** 凭据已写进 `agent/config.ini` 的 `[asr]` 段(仅本机,勿外传)。
- **DeepSeek** key 沿用 `[deepseek]` 段。

## 二、运行

```bash
cd agent
python -m ai_agent.main            # 或 start_ai.bat;--no-voice 可关语音
```

1. 开游戏、进房、开始接管(面板「脚本总控」)。
2. 有人报警/开会 → **自动**开始采集 YY 音频并转写(面板右上「语音:会议中」)。
3. 轮麦按游戏内会议图标顺序自动推进:报警人 → 从左到右、从上到下(仅存活者;
   由 L1 的 `state.meeting.speaking_order` 提供)。
4. 轮到 AI:模型立刻生成发言(位次越靠前思考档越低、话越短)→ XTTS 合成 →
   播进 CABLE Input → YY 里大家听到。**AI 播报期间自动闭麦**(不上传自己的声音给转写)。
5. 全部说完 → 自动表决最怀疑的人(模型综合全场发言+行程+怀疑度)。
6. 散会 → 自动生成「会议后行动目标」(注入行为引擎:坏人优先击杀目标、巡逻守房)。
7. 对局结束 → 自动复盘写入 `agent/data/memory/`(经验教训+玩家印象,下局会议自动注入提示词)。

## 三、整局托管(自托管一整场游戏)

面板左列「整局托管」卡片,或 HTTP `POST /api/session`。它负责把**一整局**串起来:
开房 → 等人/bot → 开局 → 会议外行为(行为引擎)→ 会议(语音管线)→ 结算 → 自动下一局。

| 形态 | 说明 |
|---|---|
| `local` | 本机服务器开房(127.0.0.1:22023)。同伴可用你的局域网 IP 直连;`bots>0` 时无需真人也能整局跑通(验收用) |
| `online` | 真在线开房(匹配服务器分配主机)。面板显示**房间码**,好友从好友列表/房间码加入,人够自动开局 |
| `freeplay` | 练习模式,无胜负结算;用 `max_meetings` 截断后重开 |

常用参数(`[session]` 段或面板):

| 参数 | 默认 | 说明 |
|---|---|---|
| `bots` | 0 | 大厅外的补充人数:开局过场结束后在 AI 身旁生成 dummy(它们会投票)。真人局设 0 |
| `min_players` | 4 | 大厅人数达到才自动开局(bot 局自动按 1 人算,开局后再补 bot) |
| `auto_start` / `auto_next` | true | 自动开局 / 结算后自动回大厅并开下一局 |
| `max_games` | 0 | 打完 N 局自动停(0=无限) |
| `max_meetings` | 0 | 会议数到点换局(主要给 freeplay) |

接口:

```bash
curl -X POST http://127.0.0.1:8765/api/session \
  -H "Content-Type: application/json" \
  -d '{"action":"start","host_kind":"local","bots":3,"min_players":4,"max_games":2}'
curl http://127.0.0.1:8765/api/session      # 阶段/房间码/人数/战绩/动作
# action: start|stop|start_now|next_game|leave_game|spawn_bots|set_options
```

**bot 局说明(验收/无人值守专用)**:dummy 会投票但不会说话/做任务,所以
①会议里它们的轮次靠 `turn_timeout` 自动跳过;②会话层在"击杀后/180s 无击杀"时
自动触发紧急会议;③1v1 平局 mod 不判负,由会话层强制结算(`debug_end_game`)。
真人对局完全不需要这些兜底,开局/结算都按游戏原生流程走。

## 四、面板「语音会议」卡片

- **发言顺序 chips**:当前发言者高亮 ▶,已说过的人变淡;轮到 AI 时显示「← 我!」。
- **实时转写**:句子边说边出(紫色为进行中);每条带说话人名。
- **音色绑定**:讯飞的 rl 音色号 → 玩家名。自动按轮麦顺序绑定;绑错了在下拉框里手动改,
  立即生效(改之前的发言归属不变)。
- **怀疑度**:模型每次发言/表决后更新的 0-100 条。
- **手动控制**:
  | 按钮 | 作用 |
  |---|---|
  | 下一位 ↵ | **通知换人发言了**(接口:`POST /api/voice {"action":"next"}`) |
  | 轮到我了 | 强制让 AI 立刻发言 |
  | 跳过我 | 本轮 AI 闭嘴 |
  | 立即表决 | 不等轮次走完直接投票 |
  | 试听 / 换音色 | XTTS 试音、xiaoyan↔xiaofeng |
- 命令行控制台同样支持:`python tools/meeting_console.py` 里 `/turn`、`/vstatus`。

## 五、节奏参数(config.ini `[voice]`)

| 参数 | 默认 | 说明 |
|---|---|---|
| `turn_end_gap` | 3.5s | 发言静默多久算"说完了",轮到下一位 |
| `turn_timeout` | 30s | 轮到某人多久没开口就跳过(YY 掉线/闭麦兜底) |
| `also_chat_in_game` | false | 语音发言是否同时发游戏内文字聊天 |

## 六、输出文件(复盘)

`agent/data/voice_out.jsonl`,每行一个事件:

```json

{"type":"voice_turn","speaker":"唯心AI","pos":1,"text":"我刚才在主舱做电线任务…","sus":{...}}

```

## 七、常见问题

| 现象 | 原因/处理 |
|---|---|
| 转写一直为空 | ①YY 播放设备不是 CABLE Input;②看面板「讯飞ASR」是否"已连"(断线会自动重连);③麦克风条没动=虚拟线里没有声音 |
| 大伙听到自己回声 | YY 回声消除被关了;或有人外放了 |
| 音色绑错人 | 下拉框手动改绑;或点「重置绑定」后按下一轮重新自动绑 |
| AI 没轮到就说话/该说没说 | 用「下一位 ↵」/「轮到我了」手动校一次;顺序也可 `set_order` 重设 |
| AI 声音太小/太快 | `[tts] speed/volume`;XTTS 服务页可试音 |
| freeplay 里测试 | 假人不说话也不出声;可用 `python tests/test_voice_e2e.py` 走完整音频链路冒烟(需要 XTTS+讯飞) |

## 八、接口汇总(HTTP)

```
GET  /api/session         整局托管状态(阶段/房间码/战绩)
POST /api/session         整局托管控制(start|stop|start_now|next_game|leave_game|spawn_bots|set_options)
GET  /api/voice           状态(轮次/绑定/转写/怀疑度/目标/记忆)
GET  /api/voice/devices   音频设备枚举
POST /api/voice           {"action":"enable|disable|next|me|skip_me|rebind|reset|
                            set_order|vote_now|test_tts|set_voice", ...}
     rebind: {"action":"rebind","rl":1,"player":"Blue"}
     set_order: {"action":"set_order","players":["Blue","唯心AI","Red"]}
```
